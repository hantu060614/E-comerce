# Product Requirements Document (PRD) - RAM Commerce

**Versi:** 1.0

## 1. Deskripsi Produk
E-commerce berbasis web yang membantu pengguna menemukan RAM yang tepat untuk perangkat mereka dengan antarmuka yang bersih dan teknis.

## 2. Fitur Utama (User Features)

| Fitur | Deskripsi | Prioritas |
| :--- | :--- | :--- |
| **Compatibility Filter** | Dropdown untuk memilih merk laptop/motherboard agar muncul RAM yang kompatibel. | P1 (Must Have) |
| **Product Comparison** | Membandingkan 2-3 produk RAM berdasarkan speed dan harga. | P2 |
| **User Profile & History** | Menyimpan alamat pengiriman dan riwayat transaksi. | P1 |
| **Smart Search** | Pencarian berdasarkan SKU atau tipe (misal: "DDR4 16GB 3200MHz"). | P1 |

## 3. Alur Pengguna (User Journey)
1. User masuk -> Menggunakan **Compatibility Filter**.
2. User memilih produk -> Masuk ke Keranjang.
3. Checkout -> Memilih metode pengiriman -> Pembayaran.
4. User menerima notifikasi WhatsApp/Email status pesanan.

## 4. Kebutuhan Non-Fungsional
- **Performance:** Halaman harus dimuat dalam < 2 detik.
- **Mobile Friendly:** Responsif di semua perangkat mobile.
- **SEO:** Optimasi metadata untuk tipe-tipe RAM tertentu.

## 5. Kriteria Keberhasilan (Success Metrics)
- Rasio konversi dari pencarian ke pembelian minimal 3%.
- Tingkat akurasi fitur kompatibilitas 100%.
